## 👨‍💻 About This Repository

This repository contains my personal DSA practice codes written during my learning phase as a **B.E. Information Technology graduate (2025) from Savitribai Phule Pune University**.

The goal is to build a strong foundation in Data Structures and Algorithms using Java as the primary language, with additional problems solved in C++ and C for deeper understanding.

Each file represents a standalone problem — coded, tested, and committed as I progressed topic by topic.
